# EquiTrade

EquiTrade is a responsive frontend-only stock trading and investment demonstration platform.

## Technology

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Vanilla JavaScript ES6
- Chart.js
- LocalStorage

## Features

- Demo registration and login
- Session handling
- User-specific LocalStorage data
- Stock search, filtering and sorting
- Stock detail pages
- Interactive illustrative charts
- Watchlist management
- Simulated buy and sell orders
- Portfolio calculations
- Average purchase price calculations
- Demo cash balance validation
- Order history
- Profile management
- Responsive desktop and mobile UI

## Running locally

No build process is required.

1. Download or clone the repository.
2. Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

3. Visit:

```text
http://localhost:8000
```

## Demo authentication

Authentication is implemented using LocalStorage for demonstration purposes only.

Do not use real passwords or sensitive personal information.

## Demo funds

Every newly registered account starts with:

```text
₹10,00,000
```

## Important disclaimer

All prices, charts, market values and news content are illustrative placeholders. They are not live market quotations, financial advice or investment recommendations.
